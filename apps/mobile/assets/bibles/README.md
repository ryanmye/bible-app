# Bundled Bible assets

The `seed.sqlite` file is generated by `scripts/build-seed-db.ts` from the root of the repo:

```bash
npm run seed:build
```

It contains three public-domain English translations:

| id   | Name                  | Language |
| ---- | --------------------- | -------- |
| kjv  | King James Version    | en       |
| asv  | American Standard Version | en   |
| web  | World English Bible   | en       |

On first app launch `installSeed()` copies this file from the app bundle into the writable app-document directory and registers each version in the `versions` table.

The built sqlite file is **not** committed. Build it locally before running the app for the first time.
